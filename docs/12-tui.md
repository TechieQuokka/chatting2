## 로그인 화면

- 앱 실행 시 `~/.chatapp/lock` (PID 파일) 확인
  - 파일 없음 → 정상 실행
  - 파일 있음 + PID 살아있음 → "앱이 이미 실행 중입니다." 안내 후 즉시 종료
  - 파일 있음 + PID 죽어있음(stale) → 잠금 파일 교체 후 정상 실행
  - PID 확인 실패 → "앱이 이미 실행 중이거나 비정상 종료됐습니다. `~/.chatapp/lock` 파일을 삭제 후 재시도하세요." 안내 후 즉시 종료

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     P2P Chat & File Transfer        │
│                                     │
│     ID : [__________________]       │
│     PW : [__________________]       │
│                                     │
│     [1] 로그인                      │
│     [2] 계정 등록                   │
│     [3] 계정 삭제                   │
│     [Q] 종료                        │
│                                     │
└─────────────────────────────────────┘
```

### 계정 등록

ID/PW 입력 후 `[2] 계정 등록` 선택:

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     계정 등록                       │
│                                     │
│     ID : [__________________]       │
│     PW : [__________________]       │
│     PW 확인 : [__________________]  │
│                                     │
│     Enter 등록  Esc 취소            │
│                                     │
└─────────────────────────────────────┘
```

- ID 중복 시: `! 이미 사용 중인 ID입니다.`
- PW 불일치 시: `! 비밀번호가 일치하지 않습니다.`
- 등록 성공 → 로그인 화면으로 복귀

### 계정 삭제

ID/PW 입력 후 `[3] 계정 삭제` 선택:

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     계정 삭제                       │
│                                     │
│  ! {ID} 계정을 삭제할까요?          │
│    이 작업은 되돌릴 수 없습니다.    │
│    (다운로드 파일은 유지됩니다)     │
│                                     │
│     y 삭제  Esc 취소                │
│                                     │
└─────────────────────────────────────┘
```

- PW 불일치 시: `! 비밀번호가 올바르지 않습니다.` → 로그인 화면 복귀
- `y` 확인 → 계정 데이터 삭제 → `계정이 삭제됐습니다.` 표시 → 로그인 화면 복귀
- `Esc` → 취소 → 로그인 화면 복귀

## 방 만들기 화면

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     방 만들기                       │
│                                     │
│     이름 : [__________________]     │
│     수명 : [1일         ▼]          │
│                                     │
│     형식 : name.suffix              │
│     예시 : dev.team, project.work   │
│                                     │
│     Enter 생성  Esc 취소            │
└─────────────────────────────────────┘
```

수명 드롭다운 옵션: `1일 (기본)` / `3일` / `7일` / `무제한`

유효성 검사 실패 시:
```
│     이름 : [dev team__________]     │
│     ! 허용 문자: 영문, 숫자, -, .   │
```

생성 성공 → 채팅/파일 화면으로 전환

## 방 목록 화면

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     방 목록                         │
│                                     │
│  ▶ dev.team       peers: 3   D-2일  │
│    project-x.work 오프라인  D-6일   │
│    lunch.chat     peers: 1   무제한 │
│    old.room       만료됨            │
│                                     │
│  ↑↓ 이동  Enter 입장  D 삭제  Esc 뒤로 │
└─────────────────────────────────────┘
```

- 온라인 피어 있으면 `peers: N` 표시
- 아무도 없으면 `오프라인` (수명 유효 시 재활성화 후 입장 가능)
- 수명 표시: `D-N일` (남은 일수), `무제한`, `만료됨`
- 재접속은 승인 없이 바로 채팅/파일 화면으로 진입
- `D` 선택 후 확인: `! {방이름} 을 삭제할까요? (y/n)`

#### 피어 수 표시 방식 (캐시 + 백그라운드 갱신)

- 화면 진입 즉시 이전 캐시 값 표시 (즉각적인 렌더링)
- 동시에 백그라운드에서 각 방의 DHT Provider Records 조회 시작
- 조회 중인 방: `확인 중...` 표시
- 조회 완료 시 자동 갱신

```
│  ▶ dev.team       peers: 3   D-2일  │  ← 캐시 값 즉시 표시
│    project-x.work 확인 중...  D-6일  │  ← 백그라운드 조회 중
│    lunch.chat     peers: 1   무제한 │
```

- 만료된 방은 화면 진입 시 자동 삭제 — 목록에 표시되지 않음
- 만료된 방이 있었다면 화면 상단에 `[알림] 만료된 방 N개가 정리됐습니다.` 표시

## 초대 코드로 입장

### 1단계 — URL 입력

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     초대 코드로 입장                │
│                                     │
│     방 URL : [__________________]   │
│                                     │
│  ↑↓ 이동  Enter 확인  Esc 취소      │
└─────────────────────────────────────┘
```

### 2단계 — 방 선택 (URL 중복 시)

DHT 조회 결과 동일 URL에 여러 방이 있을 경우에만 표시:

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     초대 코드로 입장                │
│                                     │
│     방 URL : network-study.dev1     │
│                                     │
│     어느 방에 입장할까요?           │
│                                     │
│  ▶  [a3f2b1c9]  #peer-a            │
│     [9d4e72ab]  #work-team          │
│                                     │
│  ↑↓ 이동  Enter 선택  Esc 취소      │
└─────────────────────────────────────┘
```

- `[앞 8자리]`: 방 내부 ID 앞 8자리 (랜덤 생성, 사실상 유일)
- `#identifier`: 초대 코드 생성자가 설정한 식별자

### 마지막 단계 — 코드 입력

URL이 1개만 매칭된 경우 방 선택 단계를 건너뛰고 바로 진입.

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     초대 코드로 입장                │
│                                     │
│     방 URL : network-study.dev1     │
│             #peer-a  [a3f2b1c9]    │
│     코드   : [__________________]   │
│                                     │
│  ↑↓ 이동  Enter 연결  Esc 취소      │
└─────────────────────────────────────┘
```

승인 대기:
```
│     승인 대기 중... (남은 시간 :42s)│
```

- 남은 시간은 코드 입력 시점부터 3분 카운트 (생성 시점 무관 — 시계 동기화 불필요)

실패:
```
│     ! 연결 실패 (거절됨)            │
│     Enter 다시 시도  Esc 취소       │
```

## 친구 목록 화면

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     친구 목록                       │
│                                     │
│  ▶ peer-a#a3f2b1c9    2026-01-10      │
│    peer-b#c91de4f7    2026-01-15      │
│    peer-c#7b0fa2e1    2026-02-01      │
│                                     │
│  ↑↓ 이동  D 삭제  Esc 뒤로          │
└─────────────────────────────────────┘
```

- 친구 초대는 채팅/파일 화면의 `/invite` 명령어를 통해서만 가능

닉네임#코드 중복 시 IP 자동 표시:
```
│  ▶ 홍길동#a3f2b1c9 (192.168.1.10)    │
│    홍길동#a3f2b1 (192.168.1.25)    │
│    김철수#b9c1d2f4    2026-02-01      │
```

- 중복이 감지된 항목에만 IP 자동 표시, 나머지는 미표시
- 전체 피어 목록(친구 목록, 방 멤버, 탐색 목록)에 동일하게 적용

`D` 선택 후 확인: `! {닉네임} 을 삭제할까요? (y/n)`

## 초대 알림 화면 (오버레이)

방 미입장 상태(메인 메뉴 등)에서 초대 수신 시 현재 화면 위에 오버레이로 표시.

초대 1건:
```
┌─────────────────────────────────────┐
│                                     │
│     초대 알림                       │
│                                     │
│  peer-a#a3f2b1c9 가 초대했습니다      │
│  dev.team                           │
│                                     │
│  Enter 수락  D 거절  Esc 나중에     │
│                                     │
└─────────────────────────────────────┘
```

초대 여러 건:
```
┌─────────────────────────────────────┐
│                                     │
│     초대 알림  (3건)                │
│                                     │
│  ▶ 1. peer-a#a3f2b1c9 → dev.team      │
│    2. peer-b#c91de4f7 → project-x     │
│    3. peer-c#7b0fa2e1 → lunch.chat    │
│                                     │
│  ↑↓ 이동  Enter 수락  D 거절  Esc 나중에 │
│                                     │
└─────────────────────────────────────┘
```

- 수락 시 해당 방으로 바로 입장 → 채팅/파일 화면으로 전환
- `Esc` (나중에): 오버레이 닫힘, 초대는 TTL 내 유효 (메인 메뉴에 알림 표시 유지)

## 설정 화면

### 카테고리 선택

```
┌─────────────────────────────────────┐
│                        v{버전}      │
│                                     │
│     설정                            │
│                                     │
│  ▶ 프로필                           │
│    네트워크                         │
│    채팅                             │
│    파일                             │
│    방 관리                          │
│    친구 관리                        │
│    언어                             │
│                                     │
│  ↑↓ 이동  Enter 선택  Esc 뒤로      │
└─────────────────────────────────────┘
```

### 프로필 설정

현재 비밀번호 확인 후 진입:
```
│     현재 비밀번호 확인              │
│     PW : [__________________]       │
│     Enter 확인  Esc 취소            │
```

항목 선택:
```
│  ▶ 닉네임 변경    현재: {닉네임}    │
│    비밀번호 변경                    │
│                                     │
│  ↑↓ 이동  Enter 수정  Esc 뒤로      │
```

### 네트워크 설정

```
│  ▶ 네트워크 모드    [인터넷]        │
│    리스닝 포트      랜덤            │
│    리스닝 IP        0.0.0.0         │
│    수동 피어 주소   0개             │
│    최대 연결 피어   50              │
│    연결 타임아웃    30s             │
│                                     │
│  ↑↓ 이동  Enter 수정  Esc 뒤로      │
```

### 채팅 설정

```
│  ▶ 로그 저장 경로  ~/.chatapp/users/{id}/logs/ │
│                                                 │
│  ↑↓ 이동  Enter 수정  Esc 뒤로                  │
```

### 파일 설정

```
│  ▶ 다운로드 경로      ~/downloads  │
│    최대 동시 다운로드  3            │
│    최대 업로드 속도    무제한       │
│    최대 다운로드 속도  무제한       │
│                                     │
│  ↑↓ 이동  Enter 수정  Esc 뒤로      │
```

### 언어 설정

```
│  ▶ 언어  [English      ▼]              │
│                                         │
│  * 변경 즉시 적용됩니다.               │
│                                         │
│  ↑↓ 이동  Enter 변경  Esc 뒤로          │
```

드롭다운 옵션: `English` / `한국어`

### 설정 항목 입력 방식

| 타입 | 동작 |
|------|------|
| 토글형 | Enter 누를 때마다 값 순환 |
| 텍스트/숫자 입력형 | Enter 시 인라인 편집 모드 |
| 목록 관리형 | Enter 시 서브 화면 진입 |

유효성 검사 실패 시:
```
│  ▶ 리스닝 포트    [99999     ]      │
│     ! 1~65535 범위의 숫자를 입력하세요 │
│     Enter 저장  Esc 취소            │
```

## 파일 선택 화면 (선택적 다운로드)

`/download <폴더> --select` 실행 시 전환:

```
┌─────────────────────────────────────┐
│  다운로드 파일 선택                 │
│  project-data/  (전체 3.2 GB)       │
├─────────────────────────────────────┤
│  [✓] project-data/                  │
│  ├─ [✓] report.pdf        1.2 GB   │
│  ├─ [✓] data.csv          200 MB   │
│  └─ [✓] images/                    │
│     ├─ [ ] photo-a.png    800 MB   │
│     └─ [✓] photo-b.png    1.0 GB   │
│                                     │
│  선택 용량: 2.4 GB / 3.2 GB        │
│  ↑↓ 이동  Space 선택  A 전체       │
│  Enter 시작  Esc 취소               │
└─────────────────────────────────────┘
```

- 폴더 선택/해제 시 하위 파일 일괄 적용
- 선택 용량 실시간 표시
- 완료 후 채팅/파일 화면으로 복귀

## 채팅/파일 화면 (메인)

### 레이아웃

```
┌──────────────────────────────────────────┐  ← 고정 (4줄)
│ room: dev.team │ peers:8 │ ↑1.2 ↓3.4MB/s │  ← 일반 상태
│ [↓] data.zip      ████████░░ 80%  2.1MB/s │
│ [↓] report.pdf    ████░░░░░░ 40%  800KB/s │
│ 외 2개 진행 중...           /downloads    │
├──────────────────────────────────────────┤
│                                           │  ↑
│  14:31 peer-a#a3f2b1c9 : 받을게            │  │
│  [새 파일] report.pdf 공유됨             │  전체
│  14:32 peer-b#c91de4f7 : 나도              │  스크롤
│  [완료] data.zip 다운로드 완료           │  │
│  [입장] peer-c#7b0fa2e1 입장               │  ↓
├──────────────────────────────────────────┤  ← 고정
│ > _                                      │
└──────────────────────────────────────────┘
```

온라인 피어 없이 입장 시 (오프라인 재활성화):
```
│ room: dev.team │ peers:0 │ 마지막 동기화: 2일 전  │
```

다른 피어 접속 후 동기화 완료 시 상태바 정상으로 복귀.

입장 중 방 수명 만료 시:
```
│ room: dev.team │ 만료됨                          │
```

```
│  [알림] 이 방의 수명이 만료됐습니다. /quit 으로 퇴장하세요.  │
│ > (비활성화)                             │
```

- 채팅 입력창 비활성화, `/quit` 제외 모든 명령어 비활성화
- 이미 진행 중인 다운로드·시딩은 그대로 유지

- 상단 고정 4줄: 상태바 1줄 + 활성 전송 최대 3줄
- 전송 3개 초과 시 마지막 줄에 요약 + `/downloads` 안내
- 전송 없을 때 빈 줄로 높이 유지 (레이아웃 흔들림 없음)
- 중간: 통합 피드 (파일 이벤트 + 채팅 + 시스템 알림) 전체 스크롤
- 하단 고정: 입력창

### 피드 이벤트 타입

| 타입 | 형식 |
|------|------|
| 채팅 메시지 | `HH:MM peer-name : 메시지` |
| 파일 이벤트 | `[↓] [↑] [✓] [⏸] [오류]` 접두사 |
| 시스템 알림 | `[입장] [퇴장] [알림]` 접두사 |
| 초대 알림 | `[초대]` 접두사 |
| 명령어 출력 | `── /명령어 ──` 구분선으로 감쌈 |

- 시각적 경계선 없음
- 텍스트 스타일(색상, 접두사)로만 구분

### 키 동작

| 키 | 동작 |
|----|------|
| `↑↓` (입력창 비어있음) | 피드 스크롤 |
| `↑↓` (입력 중) | 명령어 히스토리 탐색 |
| `Enter` | 명령어 실행 |
| `Esc` | 취소 |

### 입장 시 안내

방 입장 시 피드에 1회 출력:
```
  [안내] /help 명령어 목록  ↑↓ 스크롤
```

### /invite 흐름

**인터넷 모드:**
```
── /invite ──────────────────────────
  [1] 초대 코드 생성  (새로운 사람)
  [2] 친구 목록에서 초대
  번호 입력 :
─────────────────────────────────────
```

**인트라넷 모드:**
```
── /invite ──────────────────────────
  [1] 주변 피어 탐색  (새로운 사람)
  [2] 친구 목록에서 초대
  번호 입력 :
─────────────────────────────────────
```

`[1] 주변 피어 탐색` 선택 시 mDNS 탐색 목록:
```
── 주변 피어 ────────────────────────
  ▶ 홍길동#a3f2b1
    김철수#b9c1d2f4
    홍길동#a3f2b1c9 (192.168.1.25)  ← #코드 중복 시 IP 자동 표시

  ↑↓ 이동  Enter 초대  Esc 취소
─────────────────────────────────────
```

선택 후 상대방 응답 대기:
```
── /invite ──────────────────────────
  홍길동#a3f2b1c9 에게 초대 전송 중...
  응답 대기 중...            Esc 취소
─────────────────────────────────────
```

### 초대 수신 피드 (방 입장 중)

초대 1건:
```
  [초대] peer-a#a3f2b1c9 가 dev.team 으로 초대했습니다  /accept
```

초대 여러 건:
```
  [초대] 1. peer-a#a3f2b1c9 → dev.team
  [초대] 2. peer-b#c91de4f7 → project-x.work
         /accept <번호> 로 수락
```

수락 시:
```
  [알림] dev.team 으로 이동합니다...
```

### /peers 출력

```
── /peers ───────────────────────────
  1. 홍길동#a3f2b1c9
  2. 김철수#b9c1d2f4
  3. 이영희#3d8e1a2b (192.168.1.25)  ← #코드 중복 시 IP 자동 표시

  /add <번호> 로 친구 추가
─────────────────────────────────────
```

### /downloads 출력

```
── /downloads ───────────────────────
  1. [↓] data.zip      80%  2.1MB/s  ★
  2. [↓] report.pdf    40%  800 KB/s
  3. [⏸] archive.tar   12%  일시정지
  4. [⏳] video.mp4     55%  대기 중 (피어 없음)
  ────────────────────────────────────
  5. [✓] notes.txt    완료  1.2 GB
  6. [✓] photo-b.png  완료  800 MB

  /pause·resume·cancel·top·up·down <번호>
─────────────────────────────────────
```

- `[⏳]` 대기 상태: 청크를 제공하는 피어가 없음 — 새 피어 접속 시 자동 재개
- 우선순위 조작 가능, `/cancel`로 취소 가능

- 진행 중 항목: 우선순위 순 정렬, ★ 최우선순위
- 완료 항목: 자동으로 하단 배치
- 완료 항목은 우선순위 조작 불가, `/cancel` 로만 제거

### /seed 출력

```
── /seed ────────────────────────────
  1. [↑] project.tar   시딩중  ↑3 peers  2.1MB/s
  2. [↑] data.zip      시딩중  ↑1 peer   800 KB/s
  3. [⏸] archive.tar   일시정지

  /seed-pause·seed-resume·remove·remove-all <번호>
─────────────────────────────────────
```

### /remove 확인

```
── /remove 1 ────────────────────────
  project.tar 공유를 중단할까요?
  로컬 파일은 유지됩니다.

  y 확인  Esc 취소
─────────────────────────────────────
```

### /remove-all 확인

```
── /remove-all 1 ────────────────────
  project.tar 공유를 중단하고
  로컬 파일도 삭제할까요?
  이 작업은 되돌릴 수 없습니다.

  y 확인  Esc 취소
─────────────────────────────────────
```

## 화면 흐름

```
앱 실행
  ↓
[로그인 화면]
  ↓
[메인 메뉴]  ← 초대 수신 시 [초대 알림 오버레이] 표시
  ├── [1] 방 만들기 → [채팅/파일 화면]
  ├── [2] 방 목록 → 선택 → [채팅/파일 화면] (재접속 시 바로 진입)
  ├── [3] 초대 코드로 입장 → URL 입력 → (중복 시 방 선택) → 코드 입력 → 승인 대기 → [채팅/파일 화면]
  ├── [4] [친구 목록 화면]  (조회/삭제만 가능)
  ├── [5] [설정 화면]
  └── [Q] 종료

[초대 알림 오버레이] (방 미입장 상태에서 초대 수신 시)
  ├── Enter 수락 → [채팅/파일 화면]
  ├── D 거절 → 오버레이 닫힘
  └── Esc 나중에 → 오버레이 닫힘 (TTL 내 재표시 가능)

[채팅/파일 화면]  ← 초대 수신 시 피드에 [초대] 알림 표시
  ├── /accept 또는 /accept <번호> → 현재 방 자동 퇴장 → 새 방 입장
  ├── /invite → [2] 친구 목록에서 초대 가능
  ├── /download <폴더> --select → [파일 선택 화면] → 복귀
  └── /quit → [메인 메뉴]
```
