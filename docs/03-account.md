# 로컬 계정 시스템

## 개요

- 한 PC에 여러 계정 등록 가능
- 동시 실행 불가 — 한 번에 하나의 계정만 로그인/실행 가능
  - 앱 실행 시 `~/.chatapp/lock` (PID 파일)로 중복 실행 차단
  - 잠금 파일 존재 시:
    1. 파일 내 PID로 해당 프로세스가 실제 실행 중인지 OS에 확인
    2. 실행 중 → "앱이 이미 실행 중입니다." 안내 후 종료
    3. 죽어있음(stale) → 잠금 파일을 현재 PID로 교체 후 정상 실행
    4. PID 확인 자체 실패(권한 문제 등) → "앱이 이미 실행 중이거나 비정상 종료됐습니다. `~/.chatapp/lock` 파일을 삭제 후 재시도하세요." 안내 후 종료
  - 정상 종료 시 잠금 파일 삭제
- ID는 로그인용 고유 식별자 (고정, 변경 불가)
- 닉네임은 채팅에서 표시되는 이름 (변경 가능)
- #코드는 계정 생성 시 Ed25519 키쌍에서 파생된 PeerId 앞 8자리 (자동 부여, 고정)
  - 16^8 ≈ 43억 가지 조합 → 수십만 명 규모에서도 충돌 확률 현실적으로 도달 불가
  - 인터넷/인트라넷 구분 없이 전체 적용

## 피어 식별 체계

피어 목록(친구 목록, 방 멤버, 탐색 목록 등)에서 3단계로 식별:

| 단계 | 표시 형식 | 적용 조건 |
|------|----------|----------|
| 1단계 | `닉네임` | 닉네임 중복 없음 |
| 2단계 | `닉네임#코드` | 닉네임 중복 있음 |
| 3단계 | `닉네임#코드 (IP)` | 닉네임#코드까지 중복 있음 |

- 중복 감지는 현재 표시 중인 목록 기준으로 자동 판단
- IP는 중복이 감지된 항목에만 자동으로 표시 (평소엔 미노출)

## 기능

- 계정 등록 (ID/PW)
- 로그인
- 계정 삭제
  - 로그인 화면에서 ID/PW 입력 후 `[3] 계정 삭제` 선택 → PW 검증 → 확인 후 진행
  - `~/.chatapp/users/{user_id}/` 전체 삭제 (rooms.enc, identity.enc 등 포함)
  - `users.json`에서 ID 제거
  - 시딩 즉시 중단 (오프라인 처리와 동일)
  - `~/downloads/`의 파일은 삭제되지 않음 (부분 다운로드 파일 및 .bf 파일 포함 — 재개 불가 상태로 로컬에 유지)
  - 해당 계정이 유일한 시더였던 파일은 다른 멤버가 보유한 청크만 남고 나머지 청크는 자연 소멸 (토렌트 방식 동일 원리)
  - 삭제 완료 후 로그인 화면으로 복귀 (앱 종료 아님, 잠금 파일 유지)
- 비밀번호 변경 — 모든 `.enc` 파일 전체 재암호화 (원자적 교체)
  1. 현재 PW로 모든 `.enc` 파일 복호화
  2. 새 PW → Argon2id → 새 암호화 키 유도
  3. 각 파일을 `*.enc.new`로 먼저 작성 완료 (`config.enc.new`, `identity.enc.new`, `rooms.enc.new`, `friends.enc.new`)
  4. 전부 작성 완료 후 `*.enc.new → *.enc`로 순차 rename (원자적 교체)
  5. 완료 후 `*.enc.new` 파일 없음 (rename으로 소멸)
  - 크래시 복구: 재실행 시 `*.enc.new` 파일 존재 감지 → 자동 삭제 후 기존 `*.enc`(이전 PW) 유지 → 이전 PW로 정상 로그인 가능
  - 크래시 후 이전 PW가 유효하므로 데이터 손상 없음
- 닉네임 변경
  - 변경 즉시 별도 브로드캐스트 없음
  - 다음 채팅 메시지 발신 시 변경된 닉네임이 자연스럽게 전파
  - 단기간 닉네임 불일치는 허용 (의도적 설계)

## 저장 구조

```
~/.chatapp/
├── lock                    ← 실행 중 PID (앱 실행 시 생성, 정상 종료 시 삭제)
├── users.json              ← 사용자 ID 목록 (평문)
└── users/
    └── {user_id}/
        ├── config.enc      ← 암호화된 설정
        ├── identity.enc    ← 암호화된 Ed25519 키쌍
        ├── rooms.enc       ← 암호화된 방 목록 + 방 키 + 파일 메타데이터
        ├── friends.enc     ← 암호화된 친구 목록
        └── logs/           ← 채팅 로그 (방별)
```

- ID 목록만 평문 (로그인 화면 표시용)
- 나머지 전부 계정 PW → Argon2id → AES-256-GCM 으로 암호화
