# 파일 공유 (토렌트 방식)

## 기본 사양

- 청크 크기: 256KB
- 해시 알고리즘: SHA-256 (청크별 + 전체 파일)
- 공유 단위: 파일 단위 또는 폴더 단위

## 토렌트 방식 전면 채용

| 항목 | 내용 |
|------|------|
| 청크 저장 | 수신 즉시 디스크 offset에 직접 기록 |
| 청크 선택 | Rarest-first (희귀한 청크 우선 요청) |
| 피어 실패 | 연결 끊김 시 다른 피어에게 자동 재요청 |
| 부분 다운로드 | .bf 파일로 bitfield 디스크 영속 저장 → 이어받기 지원 |
| Swarming | 청크 수신한 피어가 즉시 시더가 됨 |

## 공유 흐름

1. `/share <파일경로>` 또는 `/share <폴더경로>` 실행
2. 256KB 청크로 분할
3. 각 청크 SHA-256 해시 계산
4. FileAnnounce 메타데이터 생성 (방 키로 암호화)
5. GossipSub 브로드캐스트
6. 수신 피어의 rooms.enc에 파일 메타데이터 영속 저장

## 다운로드 흐름

1. `/list` → 공유 파일 목록 확인
2. `/download <파일>` 실행
3. 피어별 bitfield 확인 (방 입장 시 수신한 정보 + BitfieldUpdate)
4. 여러 피어에게 동시 ChunkRequest 전송 (Rarest-first)
5. ChunkResponse 수신 → SHA-256 해시 검증
6. 검증 통과 → 디스크 offset에 직접 기록
7. BitfieldUpdate 브로드캐스트
8. 전체 청크 완료 → 전체 파일 해시 최종 검증

## 청크 해시 검증 실패 처리

| 단계 | 동작 |
|------|------|
| 검증 실패 즉시 | 해당 피어의 해당 청크를 블랙리스트 → 다른 피어에게 즉시 재요청 |
| 동일 피어 3회 연속 실패 | 해당 피어 연결 차단 + 로그 기록 |
| 재요청 가능한 피어 없음 | 해당 청크 보류 → 새 피어 연결 시 재시도 |

- 1~2회 실패는 일시적 네트워크 오류로 허용
- 3회 연속 실패 시 악의적 피어로 간주하여 차단
- 차단된 피어 정보는 세션 내에서만 유지 (앱 재시작 시 초기화)

## 폴더 공유

- 폴더 내 파일 목록 + 디렉토리 구조를 메타데이터에 포함
- 다운로드 시 기본값: 폴더 전체
- 선택적 다운로드: `/download <폴더> --select` 로 파일 선택 화면 진입

## 부분 다운로드 재개

- 각 다운로드 파일과 함께 `.bf` bitfield 파일 저장
- 앱 재시작 또는 재접속 시 `.bf` 파일로 완료 청크 파악
- 미완료 청크만 이어받기

```
download/
├── largefile.bin
└── largefile.bin.bf
```

### .bf 쓰기 규칙

- 청크는 불규칙한 오프셋에 기록되므로 `.bf`가 유일한 완료 상태 진실의 원천
- 청크마다 즉시 `.bf` 플러시 (`.bf` 최대 크기 ~5KB → 오버헤드 무시 가능)
- 쓰기 순서: `청크 데이터 기록` → `.bf 메모리 업데이트` → `.bf 디스크 플러시`
- 이 순서 덕분에 크래시 시 항상 안전한 방향으로만 불일치 발생
  - 최악의 경우: 마지막 1개 청크 재다운로드 (데이터 무결성 보장)

## 병렬 다운로드

- 청크 레벨: 한 파일의 청크를 여러 피어에서 동시 수신
- 파일 레벨: 여러 파일을 동시 다운로드
- 대역폭: 단순 연결 수 제한 (tit-for-tat 없음)

## 다운로드 우선순위 관리

- 목록 순서가 우선순위 (위일수록 청크 요청 우선 배분)
- 완료된 항목은 자동으로 목록 하단으로 이동
- 완료 항목은 우선순위 조작 불가

## 시딩 상태

| 상태 | 설명 |
|------|------|
| 활성 | 방 입장 시 로컬 파일 자동 시딩 |
| 일시정지 | 시딩 중지, 로컬 데이터 유지, 재개 가능 |
| 중단 | 시딩 목록에서 제거, 로컬 파일 유지 또는 삭제 선택 |

## 방 퇴장 시 파일 동작

- 시딩 일시정지 (다른 피어에게 청크 제공 중단)
- 로컬 파일 유지
- 재입장 시 자동 시딩 재개

## CLI 명령어

### 공유

| 명령어 | 설명 |
|--------|------|
| `/share <경로>` | 파일 또는 폴더 공유 시작 |
| `/list` | 방의 공유 파일 목록 |

### 다운로드 (인덱스 기반)

| 명령어 | 설명 |
|--------|------|
| `/download <파일>` | 파일 전체 다운로드 시작 |
| `/download <폴더> --select` | 선택적 다운로드 화면 진입 |
| `/downloads` | 전체 다운로드 현황 목록 |
| `/pause <번호>` | 다운로드 일시정지 |
| `/resume <번호>` | 다운로드 재개 |
| `/cancel <번호>` | 다운로드 취소 + 부분 다운로드 파일 및 .bf 파일 삭제 |
| `/top <번호>` | 최우선순위로 이동 |
| `/up <번호>` | 우선순위 한 단계 올리기 |
| `/down <번호>` | 우선순위 한 단계 내리기 |

### 시딩 (인덱스 기반)

| 명령어 | 설명 |
|--------|------|
| `/seed` | 시딩 목록 및 상태 |
| `/seed-pause <번호>` | 시딩 일시정지 |
| `/seed-resume <번호>` | 시딩 재개 |
| `/remove <번호>` | 시딩 중단 + 목록 제거 (로컬 파일 유지) |
| `/remove-all <번호>` | 시딩 중단 + 목록 제거 + 로컬 파일 삭제 |

## Transfer Task 내부 상태 (파일별)

| 항목 | 설명 |
|------|------|
| 파일 메타데이터 | 해시, 크기, 청크 수, 디렉토리 구조 |
| 청크별 상태 | 미보유 / 요청중 / 완료 |
| 피어별 bitfield | 누가 어떤 청크를 갖고 있는지 |
| bitfield 파일 | .bf 파일로 디스크에 영속 저장 |
| 다운로드 우선순위 | 목록 내 순서로 관리 |
