# 채팅

## 개요

- 채팅은 보조 기능 — 핵심은 파일 공유
- 방에 입장한 현재 온라인 사용자끼리만 메시지 송수신
- 오프라인 메시지 없음 (서버 없는 완전 P2P)

## 채팅 로그

- 로컬에만 저장 (방별 로그 파일)
- 재접속 시 본인이 이전에 보낸/받은 메시지만 표시
- 오프라인 중 다른 사람의 대화는 수신 불가 (정상 동작)

## CLI 명령어

### 채팅/방

| 명령어 | 설명 |
|--------|------|
| `/quit` | 방 나가기 |
| `/peers` | 현재 연결된 피어 목록 (번호 포함) |
| `/refresh` | 방 전체 상태 재동기화 (피어/파일/bitfield) |
| `/add <번호>` | 해당 번호의 멤버를 친구로 추가 |
| `/nick <새닉네임>` | 닉네임 변경 |
| `/invite` | 초대 코드 생성 또는 친구 초대 |
| `/accept` | 대기 중인 초대 수락 (1건) |
| `/accept <번호>` | 대기 중인 특정 초대 수락 (여러 건) |
| `/help` | 전체 명령어 도움말 |

### 파일 공유

| 명령어 | 설명 |
|--------|------|
| `/share <경로>` | 파일 또는 폴더 공유 시작 |
| `/list` | 방의 공유 파일 목록 |
| `/download <파일>` | 파일 전체 다운로드 |
| `/download <폴더> --select` | 선택적 다운로드 화면 진입 |
| `/downloads` | 전체 다운로드 현황 |
| `/seed` | 시딩 목록 및 상태 |

### 다운로드 관리 (인덱스 기반)

| 명령어 | 설명 |
|--------|------|
| `/pause <번호>` | 다운로드 일시정지 |
| `/resume <번호>` | 다운로드 재개 |
| `/cancel <번호>` | 다운로드 취소 + 부분 다운로드 파일 및 .bf 파일 삭제 |
| `/top <번호>` | 최우선순위로 이동 |
| `/up <번호>` | 우선순위 올리기 |
| `/down <번호>` | 우선순위 내리기 |

### 시딩 관리 (인덱스 기반)

| 명령어 | 설명 |
|--------|------|
| `/seed-pause <번호>` | 시딩 일시정지 |
| `/seed-resume <번호>` | 시딩 재개 |
| `/remove <번호>` | 시딩 중단 + 목록 제거 (로컬 파일 유지) |
| `/remove-all <번호>` | 시딩 중단 + 목록 제거 + 로컬 파일 삭제 |

## /refresh 명령어

방 전체 상태를 재동기화하는 명령어입니다.

### 사용 시나리오

- 피어 목록이 실제와 다를 때
- 파일 목록이 갱신되지 않을 때
- 네트워크 일시 끊김 후 복구 시
- DHT 동기화 문제 발생 시

### 동작

1. DHT GetProviders 재요청 → 피어 목록 갱신
2. DHT GetRecord 재요청 → 파일 목록 갱신
3. 모든 피어에게 BitfieldRequest 재전송 → 청크 보유 현황 갱신

### 주의사항

- 활성 방에 입장한 상태에서만 사용 가능
- 네트워크 트래픽이 일시적으로 증가할 수 있음
- DHT 응답이 느린 경우 완료까지 수 초 소요 가능

## 닉네임

- 채팅에서 보여지는 표시 이름 (변경 가능)
- 계정 ID와 별개
