# 설정 항목

## 프로필

| 항목 | 설명 |
|------|------|
| 닉네임 변경 | 채팅에서 보여지는 이름 |
| 비밀번호 변경 | 계정 PW (모든 .enc 파일 전체 재암호화) |
| ID | 고정, 변경 불가 |

## 네트워크

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 네트워크 모드 | 인터넷 모드 | 인터넷 / 인트라넷 |
| 리스닝 포트 | 랜덤 | 고정 포트 지정 (방화벽 대응) |
| 리스닝 IP | 0.0.0.0 | 바인딩할 인터페이스 |
| 수동 피어 주소 목록 | 비어있음 | 다른 서브넷 피어 multiaddr 등록 |
| 최대 연결 피어 수 | 50 | 동시 피어 연결 제한 |
| 연결 타임아웃 | 30s | idle connection timeout |

## 채팅

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 채팅 로그 저장 경로 | `~/.chatapp/users/{id}/logs/` | 방별 로그 파일 저장 위치 |

## 파일

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 다운로드 저장 경로 | `~/downloads` | 파일 다운로드 위치 |
| 최대 동시 다운로드 수 | 3 | 동시 다운로드 파일 수 제한 |
| 최대 업로드 속도 | 무제한 | MB/s 단위 업로드 대역폭 제한 |
| 최대 다운로드 속도 | 무제한 | MB/s 단위 다운로드 대역폭 제한 |

## 방 목록

| 항목 | 설명 |
|------|------|
| 초대받은 방 목록 확인 | 방 이름, 내부 ID 포함 |
| 개별 방 기록 삭제 | 방 키 포함 모든 관련 데이터 제거 |

- 방 목록 화면(`D` 키)에서도 삭제 가능 — 빠른 접근용
- 설정의 방 관리는 방 목록 화면에 진입하지 않고 일괄 관리할 때 사용
