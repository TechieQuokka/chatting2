# 친구 시스템

## 자동 등록

초대 방식에 따라 친구 등록 대상이 다름:

| 초대 방식 | 자동 친구 등록 대상 | 비고 |
|----------|-------------------|------|
| 인터넷 초대 코드 | **승인자** + 피초대자 | 코드 생성자 ≠ 승인자일 수 있음 |
| mDNS 직접 선택 | **초대자(선택자)** + 피초대자 | 초대자가 직접 연결을 개시함 |
| 친구 초대 (PeerId 직접) | **초대자** + 피초대자 | 초대자가 직접 연결을 개시함 |

- 인터넷 초대 코드 방식에서 코드 생성자(A)와 승인자(B)가 다를 경우:
  - B와 피초대자(C)가 자동 친구 등록
  - A의 피드에 `[알림] C가 입장했습니다` 표시 → A는 `/add`로 수동 친구 추가 가능
- 같은 방의 그 외 멤버는 자동 등록되지 않음

## 수동 추가

- `/peers` 명령어로 번호가 붙은 현재 방 멤버 목록 확인
- `/add <번호>` 명령어로 해당 번호의 멤버를 친구로 추가

## 저장 정보

- 상대방 닉네임#코드 (예: `홍길동#a3f2b1c9`) — 메시지 수신 시 최신 닉네임으로 자동 갱신
- 상대방 PeerId
- 최초 연결 시간

## 관리 기능

- 친구 목록 조회
- 친구 삭제
- 친구에게 직접 방 초대 (초대 코드 없이 저장된 PeerId로 연결)
